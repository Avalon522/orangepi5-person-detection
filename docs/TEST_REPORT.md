## 限制
- HTTP 耗时不等于人进入到网页显示的端到端延迟。
- 同步上传会影响处理速度，网络失败可造成最多约 2 秒的单次等待。
- 进入报警发送失败目前不会可靠重放；进程重启后当前有人可产生新的进入事件。
- SSH 窗口关闭、系统睡眠、断电或异常可能停止程序，不是系统服务。
- 无身份识别、目标跟踪、禁区 ROI、声光报警或可靠消息队列。
- 历史图片和日志没有自动清理策略，长期运行需监控空间。
